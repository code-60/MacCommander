# MacCommander

MVP аналога Total Commander для macOS на стеке `Tauri + React + TypeScript`.

## Стек

- `Tauri 2` (desktop shell + Rust backend)
- `React 19` + `TypeScript`
- `Vite`

## Команды

```bash
npm install
npm run tauri:dev
```

Сборка frontend:

```bash
npm run build
```

Сборка desktop-приложения:

```bash
npm run tauri:build
```

## Что уже работает

- Две независимые панели с чтением реальной файловой системы
- Навигация по папкам (`..`, двойной клик, `Enter`, `Backspace`)
- Навигация по списку клавиатурой:
  - `ArrowUp` / `ArrowDown` перемещение курсора
  - `Shift + ArrowUp/Down` диапазонное выделение
  - `Space` переключение выделения текущего объекта
- Мультивыделение (`Cmd/Ctrl + click`, `Shift + click`)
- Пакетные операции с очередью и прогрессом в статус-баре:
  - копировать
  - переместить
  - дублировать
  - удалить
  - создать папку
  - переименовать (для одного объекта)
- Переключение активной панели через `Tab`
- Drag & Drop между панелями:
  - по умолчанию копирование
  - `Option` при drop: перемещение
- Контекстное меню по правому клику
- Quick Look:
  - `Shift + Space`
  - `Cmd + Y`
- Настройки отображения:
  - показ скрытых файлов (`Cmd + H` или кнопка)
  - сортировка по имени/размеру/дате, asc/desc
- Горячие клавиши commander-стиля:
  - `F2` переименовать
  - `F5` копировать
  - `F6` переместить
  - `F7` новая папка
  - `F8` / `Delete` удалить
  - `Cmd + D` дублировать
